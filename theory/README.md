# Theory pack — Covered Call A vs B

The A-vs-B model (A = full-notional OTM overwrite, B = premium-matched partial-notional
ATM overwrite) and everything that derives from it.

## Start here

1. **`ab_core.py`** — the live model (Black-Scholes + wing skew tilt + `solve()`/`scenario_grid()`/`self_check()`).
2. **`AB_explorer.html`** — interactive slider explorer, open directly in a browser (mirrors `ab_core.py`).
3. **`AB_explorer.ipynb`** — same explorer as a notebook, plus the §2 scenario-grid deliverable (generated by `_build_nb.py`).
4. **`00_theory_derivation_en.md`** (or `00_theory_derivation_zh.md`, or the generated `00_theory_derivation.pdf`) — canonical derivation: single-period return, all six OTM/ATM/ITM × full/partial cases, alpha decomposition, the design problem, Greeks, multi-period compounding, frictions. All notation originates here.
5. **`00_theory_comparative_statics.md`/`.html`** — Chinese-language comparative statics for all five pricing parameters in one document: flat $\sigma$ → $r_f$ → stock-borrow carry $b$ (+ dividend-yield pricing channel $q$) → tenor $\tau$ → skew (`wing`/$\sigma_{\mathrm{ATM}}$).
6. **`00_theory_dashboard_desk_view.md`** — the dashboard's desk/distribution layer (2026-08-10): notional translation (degree-1 homogeneity), the model-free slice-value identity $\tilde y = E^Q[(r-c)^+]$ (equal premium ⇔ equal-Q-value slices ⇔ $E^Q[D]=0$, and $E^P[D]=\tilde Y(\rho(c_B)-\rho(c_A))$), exercise probabilities ($N(d_2)$ + the smile-consistent digital), the wing feasibility domain that clamps the explorer's skew slider, and the strike × tenor term grid.

The `.html` twins for #4-5 are self-contained (marked.js + KaTeX from CDN, embedded markdown source) — just open them in a browser, no build step. GitHub renders the `.md` source directly too (they use `$...$`/`$$...$$`, not `\(...\)`/`\[...\]`, which GitHub's math renderer ignores).

**A note on those `.html` viewers**: marked.js parses the embedded markdown *before* KaTeX ever sees it, so any backslash-escaped punctuation inside `$...$`/`$$...$$` (`\%`, `\,`, `\;`, `\{`, `\}`) gets silently unescaped one level too early — `\%` becomes a bare `%`, which KaTeX then treats as a LaTeX comment and truncates the rest of the line. Bare `**`/`*` used as math (e.g. $r^{**}$, $\delta^*$) can also collide with markdown's bold/italic parsing. Both `00_theory_derivation_en.md` and `00_theory_comparative_statics.md` have been fixed (double-escaped where needed) and verified to render cleanly end-to-end; keep this in mind if you add new formulas with those characters.

## Model conventions

- `q` is the annualized continuous dividend yield used for option pricing.
- `d_T=D_{0\to T}/S_0` is the realized period dividend cash return used in the
  strategy payoff.  `ab_core.Params.dividend_return` supplies it explicitly;
  if omitted, the toy model uses `exp(q*tau)-1`.
- `borrow` is a stock-borrow / carry adjustment in the option forward, not a
  funding spread paid by the long-stock investor.
- The exact risk-neutral payout identities assume European calls (or American
  calls for which early exercise is irrelevant) held to expiry.
- The skew conventions are equivalent at the 5% anchor:
  `sigma(c)=sigma_ATM-s*c` and
  `sigma(c)=sigma_ATM+wing*(c/0.05)`, so `wing=-0.05*s`.
